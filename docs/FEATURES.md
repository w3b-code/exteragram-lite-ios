# Состояние переноса Lite 12.10.6

Полный порт ещё не завершён. Здесь различаются определения параметров, подключённые функции и поведение, проверенное в собранном приложении. До реального запуска на iPhone последний статус не присваивается.

[Реестр всех 137 параметров](PREFERENCES.md) отдельно показывает определения и реальные обращения из кода потребителей. Сейчас подключены потребители 19 параметров; это не процент готовности всего мода, поскольку объём функций различается.

## Остальной объём

Крупные функции, для которых пока нет завершённой iOS-реализации: полный экспорт Lite с вложениями/Takeout/датами и исходной схемой, лента, Pill Stack, AI-провайдеры и локальная модель, редактор наборов иконок, статусы воспроизведения музыки, дополнительные настройки камеры и медиа, оформление и анимации, управление реакциями и расширенные действия сообщений. Для расшифровки ещё не воспроизведены Vosk-модели, их загрузка и AI-постобработка; Microsoft не доступен из интерфейса без собственной конфигурации. Изменения базового Telegram вне `com.exteragram` тоже требуют сопоставления.

Android-движки CameraX/AICore, JNI-библиотеки и APK updater нельзя считать перенесёнными из-за наличия одноимённого параметра. Для них нужна подходящая реализация iOS и отдельная проверка. Механизмы push/общих контейнеров также зависят от профиля, которым пользователь подпишет IPA.
