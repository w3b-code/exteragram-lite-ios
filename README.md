# exteraGram Lite для iOS

Нативный порт выбранной exteraGram Lite 12.10.6 на основе исходников Telegram iOS. Разработка продолжается: полного совпадения функций и проверенного IPA пока нет.

Цель сборки — **IPA для iPhone без подписи**. Подпись выполняется пользователем в Feather. Сертификат, закрытый ключ и provisioning profile в GitHub не нужны.

## Что уже написано

- Модуль настроек: восстановлены ключи, типы, enum-порядок и начальные значения 137 параметров основного конфига Lite.
- Локализации: 34 языка, 18 965 строк и английский fallback.
- Интеграционные патчи для настоящего клиента Telegram: полные числовые счётчики, секунды в сообщениях, значок редактирования, скрытие кнопки пересылки и панели историй, отключение виброотклика.
- Скрытие постоянных строк реакций отдельно для каналов, групп и личных чатов.
- Настройки клавиатуры и приветственного стикера, Zalgo-фильтр, скрытие собственного номера, Markdown, запятая после упоминания и отдельная камера без плитки preview.
- Оформление ответов: цвета авторов, фоновые эмодзи и заливка. Переносимое ядро ленты написано и протестировано; экран ленты ещё не подключён.
- Перевод текста через Telegram API и адаптеры Google/Yandex и Microsoft с вводом своего Azure-ключа; локальная расшифровка скачанного аудио через Apple Speech.
- Экспорт доступной облачной истории чата в HTML/JSON с текстом и метаданными файлов. Вложения и Takeout пока не перенесены.
- Собственный пункт exteraGram Lite в настройках приложения. На экране показываются только параметры с подключёнными потребителями.
- GitHub Actions: сборка и тесты Swift-модулей, отдельная ручная сборка arm64 IPA и проверка его структуры.

Этот перечень описывает написанный код. Результат компиляции, проверки на устройстве и степень покрытия функций фиксируются отдельно; наличие определения настройки не означает перенос её функции. См. [состояние функций](docs/FEATURES.md).

## Сборка и установка

1. Для авторизации клиента получить собственные `api_id`/`api_hash` на [my.telegram.org/apps](https://my.telegram.org/apps) и добавить `TELEGRAM_API_ID`/`TELEGRAM_API_HASH` в repository Secrets. Публичная тестовая пара Telegram ограничена и не подходит для распространения рабочего клиента.
2. Открыть Actions → **iOS packages and unsigned IPA** → Run workflow.
3. Для первой проверки модулей отключить `build_ipa`. Для IPA оставить включённым.
4. Только после успешной сборки скачать артефакт с `exteraGram-Lite-unsigned.ipa`, распаковать ZIP-артефакт и импортировать IPA в Feather.

Подробности: [BUILD.md](docs/BUILD.md), [адаптация хранения и ограничений профиля Feather](docs/SIDELOAD.md). До запуска сборки репозиторий остаётся приватным по указанию пользователя; перед использованием бесплатного стандартного runner его видимость меняется на публичную.
